03

Audit my notebook

Muse Spark reads a notebook, finds the look-ahead leak, and proposes a fix. A finding is Proven only if a generated test fails on the original code, passes with the fix, and passes on a clean control.

Backtest Breaker audits strategies. It does not give investment advice.
Every number on this page is read from saved live-run files (demo/MANIFEST.json); none is typed by hand or computed by the model.
